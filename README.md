# Навигатор по олимпиадам

Сайт и Telegram-бот: какая олимпиада в какой вуз и на какое направление даёт БВИ
или 100 баллов, какие ЕГЭ сдавать и когда ближайший этап.

Сейчас готовы: схема базы данных, парсер перечня РСОШ (текущий год и архив),
список предметов ВсОШ и Telegram-бот с поиском, карточками олимпиад, подписками
и напоминаниями об этапах.

## Структура

```
app/
  cli.py              командная строка: python -m app.cli ...
  catalog.py          каталог олимпиад за все годы: склейка переименований, поиск
  stages.py           этапы олимпиад, расчёт напоминаний, импорт из CSV
  bot/
    main.py           Telegram-бот на aiogram 3
    texts.py          тексты сообщений
    storage.py        SQLite: пользователи, подписки, этапы, журнал уведомлений
    notifier.py       рассылка напоминаний
  config.py           настройки из окружения / .env
  fetch.py            аккуратная загрузка страниц (User-Agent, паузы, повторы)
  exporters.py        сохранение в JSON и CSV
  parsers/
    rsr.py            парсер перечня с rsr-olymp.ru
    subjects.py       разбор колонки «Предметы» с составными названиями
    vsosh.py          предметы Всероссийской олимпиады школьников
  db/
    psql.py           миграции и выполнение SQL через psql
    sql_loader.py     генерация идемпотентного SQL загрузки
db/migrations/        схема базы (001_init.sql)
tests/                тесты и фикстура с настоящей разметкой РСОШ
```

## Быстрый старт через Docker

```bash
cp .env.example .env          # поменяйте пароль
docker compose up -d db
docker compose run --rm app db migrate
docker compose run --rm app rsr fetch                           # перечень 2026/27
docker compose run --rm app rsr fetch --years 2025 2024 2023 2022  # архив: диплом действует 4 года
docker compose run --rm app rsr load data/rsr/rsr_2026-27.json data/rsr/rsr_2025-26.json \
    data/rsr/rsr_2024-25.json data/rsr/rsr_2023-24.json data/rsr/rsr_2022-23.json
docker compose run --rm app vsosh load --year 2026/27
docker compose up -d bot      # Telegram-бот (токен в .env)
```

Для перечня 2026/27 должно получиться **60 олимпиад и 272 профиля**
(сверено с сайтом 15.10.2026). Если цифры другие или появились строки с `!`,
значит изменилась вёрстка или в предметах встретился новый вариант составного
названия: добавьте его в `COMPOUND_SUBJECTS` в `app/parsers/subjects.py`.

Результаты лежат в `data/rsr/`: JSON для базы, CSV для просмотра в Excel,
исходный HTML в `data/rsr/raw/`.

## Без Docker

Нужны Python 3.11+ и клиент `psql`.

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env          # укажите DATABASE_URL
python -m app.cli db migrate
python -m app.cli rsr fetch
python -m app.cli rsr load data/rsr/rsr_2026-27.json
```

Если сайт РСОШ недоступен с сервера, сохраните страницу из браузера и разберите её:

```bash
python -m app.cli rsr parse saved.html --url https://rsr-olymp.ru/archive/2025
```

## Telegram-бот

1. Скачайте перечни за 5 лет (диплом действует 4 года):
   ```bash
   python -m app.cli rsr fetch
   python -m app.cli rsr fetch --years 2025 2024 2023 2022
   ```
2. Впишите токен от @BotFather в `.env`: `TELEGRAM_BOT_TOKEN=...`
3. Запустите:
   ```bash
   pip install -r requirements.txt
   python -m app.cli bot run        # на Windows: py -m app.cli bot run
   ```

Бот работает, пока открыто окно консоли; остановка — Ctrl+C.

**Если бот получает сообщения, но не отвечает** (в консоли `TelegramNetworkError: Request timeout`):

```bash
python -m app.cli bot check
```

Команда проверит связь с Telegram по IPv4 и IPv6 и подскажет, что делать. По умолчанию бот
ходит только по IPv4 (`TELEGRAM_FORCE_IPV4=1`): у многих провайдеров IPv6-маршрут до Telegram
«висит». Если провайдер замедляет Telegram, нужен прокси: `pip install aiohttp-socks` и в `.env`
`TELEGRAM_PROXY=http://логин:пароль@host:port` (или `socks5://…`). Надёжнее всего — запустить
бота на сервере за пределами этой сети. Подписки хранятся
в `data/bot.sqlite3`. После скачивания нового перечня бота нужно перезапустить.

Что умеет бот:

- **Поиск** по названию, сокращению (ВсОШ, МОШ, НТО, ВШЭ, МГУ, СПбГУ, ОММО…), профилю
  или предмету, в том числе вместе: «ломоносов химия», «нто искусственный интеллект».
  Сначала идёт ВсОШ, затем олимпиады с более высоким уровнем профиля.
- **Карточка олимпиады**: профили текущего перечня, сгруппированные по уровням, что
  изменилось к прошлому году (⬆️⬇️ уровень, 🆕 новый профиль, ✖️ убран), профили прошлых
  лет, ближайшие этапы. Кнопка «Подробнее» — предметы и уровни каждого профиля по годам.
- **Навигация кнопками в одном сообщении**: меню → результаты (по 8 на странице) →
  карточка → «Назад». Новое сообщение бот присылает только в ответ на запрос пользователя.
- **Подписки** и **напоминания**: о регистрации — за 3 дня и в последний день,
  об этапах — за неделю, за день и в день этапа. Пишет только с 9:00 до 21:00 по Москве.

Олимпиады, которые в разные годы назывались по-разному, склеиваются в одну:
по названию без мелких отличий, по тексту в кавычках или по сайту — только если
записи из разных лет. Так «Innopolis Open» и «Олимпиада Иннополиса» — одна карточка,
а две разные «Архитектуры и искусства» (Ростов и Тюмень) — две.

### Этапы олимпиад

Пока даты загружаются из CSV (автоматическая загрузка с olimpiada.ru — следующий шаг):

```csv
olympiad;kind;title;starts_at;ends_at;profile;source_url
Физтех;registration;Регистрация;01.10.2026;15.11.2026;;https://olymp.mipt.ru
Олимпиада школьников «Физтех»;qualifying;Отборочный этап;2026-11-20;2026-11-22;математика;
```

- `olympiad` — название, сокращение или любой запрос, по которому находится ровно одна олимпиада;
- `kind` — `registration`, `qualifying`, `final`, `results` или `other`;
- даты — `ГГГГ-ММ-ДД` или `ДД.ММ.ГГГГ`; для регистрации важна `ends_at` (дедлайн);
- `profile`, `title`, `source_url` — необязательные.

Пример выше показывает формат, даты в нём выдуманные — берите настоящие с сайтов олимпиад.

```bash
python -m app.cli stages import stages.csv   # повторный импорт обновляет даты, а не дублирует
python -m app.cli stages list
```

## Как устроены данные

- **Перечень хранится по учебным годам.** Уровень олимпиады меняется от года к году,
  а льгота зависит от уровня в год получения диплома. Поэтому загружаем 4 последних года.
- **Олимпиада узнаётся между годами по ключу** — названию без порядкового номера
  («XIX Южно-Российская…» и «XVIII Южно-Российская…» — одна олимпиада).
- **Одна олимпиада может идти несколькими группами строк** с одним номером, если у
  профилей разные сайты («Росатом», «Санкт-Петербургская олимпиада»). Парсер их объединяет,
  а сайт хранит у каждого профиля.
- **Колонка «Предметы» делится с учётом запятых внутри названий**
  («фотоника, приборостроение, оптические и биотехнические системы и технологии»),
  сокращённые варианты приводятся к полному названию.
- **Загрузка идемпотентна.** Строки перечня за год перезаписываются целиком, льготы при
  этом не страдают: они ссылаются на олимпиаду и название профиля.
- **У льготы обязательны год приёма, статус и ссылка на источник.** Статус `prev_year` —
  данные прошлого года приёма, их показываем с плашкой, пока вуз не опубликовал новые.
